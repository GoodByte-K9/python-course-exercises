## Python Course Exercises
The purpose of this repo is to start tracking my course exercises to see my progress and to have an easy-to-access place I can use to reference code, if needed.

My interest in Python was sparked on March 12th, 2026, and I started serious study on June 1st, 2026, following the "100 Days of Code" course on Udemy. I've already done 60+ projects ranging from simple games and apps to my first steps in backend web dev. My goal is to become a Python developer in 1-year's time (which has proved to be quite the challenge for a new father with a day job).

Everything is hand-coded; no AI was used to generate code. Using AI to generate all code for course content would be self-defeating for the purpose of learning it. I only used AI as a personal tutor to explain foreign concepts to me, or for problems I couldn't solve, and even then I instructed it to give minimal hints so I could try and figure things out myself.
